# SIC Lab

The open lab of the Spatial Intelligence Collective: sub-national data for India, Brazil and
Venezuela, spatial statistics that run in the browser (spatial weights, Moran's I, LISA,
Getis-Ord Gi*, Gini and Theil, OLS and GWR), a map composer, and tutorials in spatial
statistics with Python that run in the page.

Live at https://lab.spatialintelligence.network/ and introduced at
https://spatialintelligence.network/learn/.

This repository holds the built site. Data are open: `/v1/<country>/<variable>.json` serves every
variable, and shapefiles for India are under `/shapefiles/`. Sources and licences are listed in
each file and in the app's Sources panel.
